# Changelog

## 0.1.0 — The Fallen Valley foundation
- Created new SafeHaven TypeScript/Vite/PlayCanvas architecture.
- Added fixed-step serializable RTS simulation.
- Added WebGPU-first / WebGL2-fallback renderer boot path.
- Added Haven and Covenant data definitions.
- Added power grid, physical resource hauling, build prerequisites, construction, production queues, projectiles, armor multipliers, veterancy, repair, sell and capture primitives.
- Added strategic Covenant production/assault behavior.
- Added IndexedDB save slots/autosave architecture.
- Added title screen, HUD, objectives, pause/save UI and touch camera gestures.
- Added primitive 3D placeholder battlefield for the first playable slice.
