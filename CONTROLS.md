# Controls

## Desktop
- Tap/click Haven unit/building: select
- Tap/click enemy with units selected: attack
- Tap/click ground: move
- A: arm attack-move, then click ground
- S: Stop via command panel in current vertical slice
- Mouse wheel: zoom
- W/A/S/D: camera pan when attack-move is not armed
- Escape: clear selection

## Touch
- Tap: select / move / attack contextually
- Two-finger drag: pan camera
- Pinch: zoom
- Large command buttons are provided for build, train, repair, sell and attack-move.

Drag-box selection, control groups, true raycast picking, and gesture-disambiguated one-finger camera behavior are tracked as Stage 1 completion work in `PROJECT_STATE.md`.
